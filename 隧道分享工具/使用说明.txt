隧道分享工具 · 使用说明
========================

作用：把电脑上的本地网站（如 localhost:3000）变成一个公网地址，发给任何人都能打开。

使用方法（三步）：
1. 从 GitHub 仓库下载完整文件夹并解压
   （仓库页绿色「Code」按钮 →「Download ZIP」，或 git clone）
2. 双击启动脚本（Mac 双击「启动.command」/ Windows 双击「启动.bat」），
   浏览器会自动打开工具页面
   （Mac 首次如提示"无法验证开发者"，请右键点它 → 打开；
    Windows 如提示"已保护你的电脑"，点"更多信息"→"仍要运行"）
3. 在输入框 localhost: 后面填端口号（如 3000），点「获取公网地址」，
   绿点亮起后复制地址发送即可

核心特性：
- 每次点击都从头到尾重新打通一条全新隧道，绝不复用旧结果
- 两种获取方式（点击后弹窗选择）：
    快速获取：立即返回地址；新地址需几十秒全球生效，期间打开会提示
    无法访问，稍候刷新即可
    验证后获取：工具先确认地址能真正打开才返回（约 10 秒至 2 分钟），
    返回即可用；遇到无效地址会自动更换重试（最多 3 次）
- 多地址并存：每次点击新开一条隧道，旧地址在工具运行期间继续有效
  （上限 5 条，超出自动淘汰最旧的；关闭工具后全部失效）
- 绝不自动出地址：不输入端口并点「获取公网地址」，页面上不会
  出现任何公网地址（打开页面是空白待命状态）
- 本地服务没起也不怕：按「启动配置.json」自动拉起对应软件
  （依赖缺失会先自动安装，即所需的全部"驱动"）
- 右侧「历史记录」面板：每获取一次公网地址都留一条（时间 + 端口 + 地址），
  点击地址即可复制，可一键清空
- 电脑重启后旧公网地址会失效：重新双击启动工具，再点一次
  「获取公网地址」即可拿到新地址（历史记录里可对比新旧地址）

环境要求：零。没装 Node.js 也没关系——双击启动时自动检测，
没有就自动下载便携版装进本文件夹（不动系统）。

给他人使用：把整个「隧道分享工具」文件夹发给对方即可：
- 无需注册任何账号，无需安装任何软件
- 文件夹自带隧道组件（组件/ 目录含 Mac 与 Windows 双版本），零下载
- Mac 双击「启动.command」，Windows 双击「启动.bat」
- 没装 Node.js 也没关系：自动下载便携版装进本文件夹，不动系统
- 首次双击的安全提示（只出现一次）：
    Mac 提示"无法验证开发者" → 右键点它选"打开"
    Windows 提示"已保护你的电脑" → 点"更多信息" →"仍要运行"
- 唯一要注意的：「启动配置.json」里的项目路径是每台电脑各一份的
  （默认写的是原作者电脑的路径）。对方想让"服务没起也能自动拉起"，
  就用记事本/文本编辑打开该文件，把路径改成对方电脑上项目的实际位置。
  不改也不影响使用：只要对方的服务已经开着，填端口号直接获取即可
- 建议发给他人前删除「历史记录.json」
  （这是你的个人使用记录，删掉不影响任何功能）
- 工具页面上也有「怎么用」按钮，以上内容对方在页面里随时能看到

注意：
- 工具检测的"本地端口"是运行工具的这台电脑自己的端口：
  服务在哪台电脑上，就把工具文件夹放到哪台电脑运行
- 电脑重启后公网地址会更新：重新双击启动即自动恢复，以页面最新显示为准
- 关闭终端/命令行窗口 = 停止隧道（自动拉起的本地服务不受影响）
- 要为新端口配置自动启动：编辑本文件夹的「启动配置.json」，
  仿照 3000 那段再加一段即可
