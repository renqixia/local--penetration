常见问题

首次打开的安全提示，一次搞懂

从网上下载的工具，第一次打开时系统会弹出安全确认。这不是文件有问题，而是电脑在保护你。按下面的官方方法确认一次，之后就不会再出现。

Mac 提示「Apple 无法验证」，怎么办？

为什么会出现：工具从网上下载，还没有 Apple 付费认证的签名。这是 Apple 对所有开源软件的统一保护（Homebrew、ngrok 等工具也一样），不代表文件有问题。

解决办法（只需一次，Apple 官方标准方式）：

  1. 在「隧道分享工具」文件夹里，右键（或按住 Control 键点）启动.command
  2. 在弹出的菜单里点「打开」
  3. 在确认框里点「打开」，终端就会正常启动工具

如果右键菜单里没有「打开」，就去：系统设置 → 隐私与安全性，找到被拦截的 启动.command，点「仍要打开」。

放心：这只是电脑让你确认一次「这个文件是你自己要用的」，之后双击即可，不再有任何提示，也不影响电脑其它安全设置。
双击提示「没有正确的访问权限」？

为什么会出现：如果是从 GitHub 网页直接点「Download ZIP」下载的压缩包，GitHub 会去掉 启动.command 的执行权限，Mac 双击就提示没有访问权限。这不是你的电脑或工具的问题。

解决办法（推荐）：改用本页下方「下载工具」按钮下载的发布版压缩包，它已保留了执行权限，解压后直接双击即可，不用输任何命令。

已下载网页版 ZIP 的备用办法：打开「终端」（Command + 空格，输入"终端"回车），先 cd 到解压出的工具文件夹，再粘贴执行下面这一行：

chmod +x 启动.command
执行一次即可，之后双击都能正常启动。这条命令只是给文件加上"可执行"权限，不涉及任何系统设置。
Windows 提示「Windows 已保护你的电脑」，怎么办？

首次双击 启动.bat 时，如果出现「Windows 已保护你的电脑」：点「更多信息」→ 点「仍要运行」即可，只此一次。

这是 Windows 对未签名程序的常规提示，和 Mac 同理：确认一次，之后正常使用。
