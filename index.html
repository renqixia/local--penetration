三步发出第一个链接

先在 Mac 上启动你要分享的网页。

01 / 打开

选择一个入口

从 Releases 下载完整发布包。双击「虚渡.app」，或运行「启动.command」打开本机网页。

02 / 建立

填入本地端口

例如本地地址是 localhost:3000，填入 3000。默认先验证公网首页，也可以选择快速获取。

03 / 分享

复制链接发给对方

访客直接用浏览器打开。分享完成后，在活动隧道里停止这一条链接。

入口切换

App 和本机网页，一次用一个

两个入口共用本机管理服务。先结束当前会话，再打开另一个入口。

本机网页 → App

App 会弹出「请先关闭网页模式」

如果网页模式还在运行，App 会暂缓启动。关闭所有虚渡网页标签页，等待约 4 秒，再在 App 点「重试」。也可以在启动终端按 Control + C 立即结束网页模式。

App → 本机网页

先退出 App，再打开网页

App 运行时，浏览器访问本机控制台只会显示切换提示。按 Command + Q 退出 App，再双击「启动.command」。

切换会结束当前会话。 已发出的临时链接会失效。如果对方还在看，等分享结束再切换。

控制台把链接是否已生成、是否通过本机探测，以及是否还在分享分开显示。

验证后交付

验证并获取链接

默认先从本机检查公网首页。通过后再复制地址，适合直接发给别人预览。

先拿地址

快速获取

地址先返回，状态显示待验证。首页有跳转或登录时，可以先拿地址，再打开实际要分享的页面确认。

分享生命周期

活动隧道

最多保留五条活动隧道。可逐条停止分享；清空历史只清除记录，不会关闭隧道。

使用前了解这几件事

介绍页、本机网页、分享链接有什么区别？

介绍页用于了解和下载虚渡。本机网页用来在你的电脑上建立及管理隧道。分享链接把访客带到你公开的本地服务，访客无需安装虚渡。

为什么验证失败，或者链接打开后断了？

验证模式从本机检查公网首页是否返回 HTTP 2xx。遇到跳转、登录页或其他状态时，可用快速模式并自行验证。链接可用性也取决于本地服务和 Cloudflare Quick Tunnels。

谁能看到分享出去的网页？

持有链接的人可以访问，公网请求经 Cloudflare 转发。请只分享允许公开的页面。本机的链接历史只保留在当前会话。

我的 Mac 能运行吗？

当前工作区的 App 构建面向 Apple Silicon 和 macOS 14 及以上。以所下载版本的发布说明为准，遇到启动问题可在 GitHub Issues 附上系统版本、芯片和提示文案。
